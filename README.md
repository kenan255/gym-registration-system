# Gym Registration System

## Project Description
A simple Gym Registration System developed using Python.

## Project Features
- Welcome message.
- Enter the user's name.
- Save the user's name in a text file.
- Check the user's age.
- Ask the user about gym registration.
- Choose a monthly or yearly membership.

## Programming Language
Python

## Tools Used
- Python
- GitHub

## How to Run
1. Download the project.
2. Open main.py using Python.
3. Run the program.
4. Follow the instructions.

To practice Python programming using:
